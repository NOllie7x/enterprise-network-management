
**Question 1**
What option under the folder redirection settings redirects everyone's folder to the same location?
答案：Basic
讲解：在组策略的文件夹重定向设置中，基本（Basic）设置可以将每个人的文件夹重定向到同一个指定的共享位置。

**Question 2**
What enables you to target specific users or computers based on criteria?
答案：Item-level targeting
讲解：项目级目标（Item-level targeting）允许管理员根据特定条件（如用户组、计算机名、IP范围、操作系统等）将首选项或策略应用到特定的用户或计算机。

**Question 3**
The standard DACL for a package object assigns read permissions to what group by default?
答案：Authenticated Users
讲解：在组策略软件分发中，软件包对象的默认自由访问控制列表（DACL）会为“经过身份验证的用户（Authenticated Users）”组授予读取和执行权限，以便用户能够访问并安装该软件。

**Question 4**
What type of application can be installed automatically when the user logs on to a computer in the domain?
答案：assigned
讲解：当应用程序被“分配（assigned）”给用户时，它会在用户登录时自动安装（或提供快捷方式在首次使用时触发安装）。

**Question 5**
A published application can be installed automatically.
答案：False
讲解：已发布（published）的应用程序不会自动安装。它仅在“控制面板”的“程序和功能”中提供，需要用户手动选择进行安装。

**Question 6**
What type of policy setting is persistent, remaining even after a computer or user object falls out of a GPO's scope until it's changed by another policy or manually?
答案：Managed policy setting
讲解：受管理的策略设置（Managed policy setting，即强制策略）具有持久性。即使对象移出了 GPO 的作用域，该设置也会保留在注册表中，直到被其他策略覆盖或手动更改。

**Question 7**
What tool within Windows Server 2016 must be used in order to change the default auditing settings?
答案：auditpol.exe
讲解：auditpol.exe 是 Windows 系统中用于配置和查看审核策略（Audit Policy）的命令行工具。

**Question 8**
Settings under the User Configuration node affect what Registry key?
答案：HKEY_CURRENT_USER
讲解：组策略中的用户配置（User Configuration）节点下的设置应用于用户，修改的是当前用户注册表配置单元，即 HKEY_CURRENT_USER。

**Question 9**
After running the Security Configuration and Analysis snap-in with a template, what does a check mark in a green circle mean?
答案：The template policy and current computer policy are the same
讲解：在“安全配置和分析”管理单元中，绿色圆圈内的对勾表示当前计算机的安全设置与导入的安全模板中的设置一致。

**Question 10**
Command scripts are just a series of commands saved in a file with a .bat extension.
答案：True
讲解：命令脚本确实就是一系列保存在扩展名为 .bat（或 .cmd）文件中的命令集合。

**Question 11**
In the User Configuration node, where are policies that determine whether a user can publish DFS root folders in Active Directory?
答案：Shared Folders
讲解：控制用户能否在 Active Directory 中发布 DFS 根文件夹的组策略设置位于“用户配置” -> “策略” -> “管理模板” -> “共享文件夹”路径下。

**Question 12**
Which of the following is not one of the criteria that can be used within an administrative templates filter?
答案：Enable Action Filters
讲解：“启用操作筛选器（Enable Action Filters）”不是管理模板筛选的标准。通常在管理模板中进行筛选时，可以使用“受管理(Managed)”、“已配置(Configured)”或“启用要求筛选器(Enable Requirements Filters)”。

**Question 13**
The Restricted Groups policy, under Security Settings, Controls group membership for both domain groups and local SAM groups.
答案：True
讲解：受限组（Restricted Groups）策略可以控制本地计算机的 SAM 组成员身份，当它链接到域级别时，也可以控制 Active Directory 中的域组。

**Question 14**
ADMX and ADML files are placed under what directory within Windows?
答案：%systemroot%\PolicyDefinitions
讲解：默认情况下，组策略的 ADMX 和 ADML 文件存储在本地 Windows 目录下的 %systemroot%\PolicyDefinitions 文件夹中。

**Question 15**
If you want to create a security template using a baseline of settings from an existing desktop computer or server, you can begin by opening secpol.msc.
答案：False
讲解：要基于现有计算机创建安全模板，应该使用“安全配置和分析（Security Configuration and Analysis）”管理单元或命令行工具 secedit。secpol.msc 是本地安全策略，主要用于配置当前计算机，而不是用来创建模板。

**Question 16**
What Active Directory object enables an administrator to configure password settings for users or groups that are different from those defined in a GPO linked to the domain?
答案：password settings object
讲解：密码设置对象（PSO，Password Settings Object）是用于实现细粒度密码策略（FGPP）的 AD 对象，允许管理员为特定用户或组配置不同于域默认策略的密码规则。

**Question 17**
When a client computer wants to connect to a service instance, what specific name type does it use to find the service?
答案：service principal name
讲解：客户端计算机使用服务主体名称（SPN，Service Principal Name）来唯一标识并在网络上查找特定的服务实例。

**Question 18**
Using default settings, if a computer's clock differs more than 5 minutes than a Kerberos message's timestamp, what happens?
答案：The Kerberos message is considered invalid
讲解：Kerberos 依赖时间戳来防止重放攻击。默认情况下，如果计算机时钟与时间戳的偏差超过 5 分钟，该 Kerberos 消息将被视为无效并拒绝。

**Question 19**
What setting specifies how long a service ticket can be used before a new ticket must be requested to access the resource for which the ticket was granted?
答案：Maximum lifetime for service ticket
讲解：“服务票证最长生存期”设置了服务票证在被要求重新获取之前，可以用于访问特定资源的最长时间。

**Question 20**
Select the term that is a record of the time a message is sent and is used in Kerberos to determine a message's validity and prevent replay attacks.
答案：timestamp
讲解：时间戳（timestamp）记录了消息发送的时间，Kerberos 用它来验证消息的有效性并防止重放攻击。

**Question 21**
Mutual authentication means that the identity of both parties is verified.
答案：True
讲解：相互身份验证（Mutual authentication）是指通信双方都验证了彼此的身份。

**Question 22**
When a client wants to connect to a service, it finds the service based solely on the instance name.
答案：False
讲解：客户端不能仅基于实例名称来查找服务，它需要通过查询服务主体名称（SPN）来定位具体的服务实例。

**Question 23**
If using virtual accounts to access the network, how are permissions added to a network resource to allow the virtual account access?
答案：The resource must have proper permissions set for ComputerName$, where ComputerName is the name of the computer attempting to access the resource.
讲解：虚拟账户访问网络资源时，是使用计算机的域账户（ComputerName$）进行身份验证的。因此，必须在网络资源上为相应的计算机账户配置权限。

**Question 24**
A service account is a user account that Windows services use to log on to a computer or domain with a specific set of rights and permissions.
答案：True
讲解：服务账户是专门供 Windows 服务使用，拥有特定权限和权利来登录计算机或域并运行服务的账户。

**Question 25**
The Default Domain Policy sets the maximum password age to what value?
答案：42 days
讲解：在默认的域策略（Default Domain Policy）中，密码最长使用期限默认设置为 42 天。

**Question 26**
What policy is a GPO linked to the Domain Controllers OU and specifies the default policy settings for all domain controllers?
答案：Default Domain Controllers Policy
讲解：默认域控制器策略（Default Domain Controllers Policy）默认链接到域控制器 OU，并为所有域控制器配置基础安全设置。

**Question 27**
What option limits the delegation to specific services running on specific computers?
答案：constrained delegation
讲解：约束委派（constrained delegation）允许管理员限制服务只能代表用户访问特定计算机上的特定服务，从而降低安全风险。

**Question 28**
Approximately 42 days after a service was configured to use a normal user account, the service has stopped working and refuses to run. An administrator has verified that the account still exists on the domain. Assuming default domain policy settings, what could be the issue?
答案：The user account password expired
讲解：默认域策略中密码最长使用期限为 42 天。如果该普通用户账户的密码未更新导致过期，服务将无法使用该账户登录，从而导致服务停止运行。

**Question 29**
Which type of ticket below is requested by an account when it wants to access a network resource, such as a shared folder?
答案：Service ticket
讲解：当账户想要访问特定的网络资源（如共享文件夹）时，需要向 KDC 请求服务票证（Service ticket）。

**Question 30**
By default, the maximum tolerance for computer clock synchronization is set to what value?
答案：5 minutes
讲解：默认情况下，Kerberos 允许的计算机时钟同步最大容差为 5 分钟。
